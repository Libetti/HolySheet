# HolySheet

Minimal SvelteKit starter for the early phase of the app.

## Scripts

- `npm install`
- `npm run dev`
- `npm run check`
- `npm run build`

## Notes

The current app is intentionally small. It gives you a clean homepage and the core SvelteKit
project structure so we can add authentication, profiles, file sharing, and AI integrations when
those decisions are ready.
